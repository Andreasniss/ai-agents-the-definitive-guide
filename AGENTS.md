# Public contribution instructions

Read `PRIVACY.md` before preparing any public commit or PR. Keep private authoring outside this repository. Run the staged and outgoing-commit privacy checks before Git or API uploads, and preserve intentionally public upstream examples and engineering evidence.

## Fork maintenance

This is a learning fork. README's introduction and contribution section own local
fork context; the book, chapter notebooks and upstream instructions retain their
authors' ownership. Keep local guide improvements in these fork-owned sections,
preserve attribution, and do not infer a license from public availability.

For notebook work, inspect the selected chapter's setup and service calls before
execution. A downloaded notebook or saved output is not a verified run. Report
the chapter, environment and cells actually exercised, and apply PRIVACY.md to
changed code and outputs before upload. No notebook execution is required for a
fork-instruction wording change.
